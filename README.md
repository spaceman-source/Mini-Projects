
# Radioactive Decay of Muons
 Overview
 
   This project investigates the radioactive decay of muons using statistical analysis and computational modeling. Muon decay provides a real-world example of exponential decay and serves as an experimental test of fundamental principles in nuclear and particle physics. The lab focuses on extracting the muon mean lifetime from decay-time data and comparing experimental results to theoretical expectations.

Objectives

Model muon decay using the exponential decay law
Model the analytical results to the numerical solution

Methods

Imported and processed decay-time data using MATLAB

Constructed plots of decay events

Applied curve fitting and linearization techniques

Evaluated goodness of fit and statistical uncertainty

Compared experimental lifetime values to accepted constants

Results

The decay-time distribution closely follows an exponential trend, consistent with theoretical predictions for muon decay. The experimentally determined mean lifetime agrees with accepted values within uncertainty, validating the decay model and experimental approach.
