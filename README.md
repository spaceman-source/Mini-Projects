# Lab Projects & Coursework
Overview

This repository contains code, simulations, and analysis scripts developed for undergraduate physics and engineering coursework, laboratory experiments, and selected academic assignments. Projects focus on applying theoretical concepts to computational models, data analysis, and experimental interpretation.

The purpose of this repository is to document technical problem-solving, scientific computing, and lab-based work, rather than polished standalone software projects.




Disclaimer
